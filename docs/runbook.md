# 每日运行与主管接管

## 启动、暂停和恢复

1. 阅读当前日期短状态及日志增量；先ADB connect，核验在线与新截图。
2. 检查暂停标记、异地登录、战斗、资源、任务解锁与当日已完成项。
3. 支持主页且无其他ALAS循环时，显式启动守护；events中的alas_started和有效日志才证明成功。
4. 守护每次最多10小时，最多3次启动，退出间隔60秒；这只是有限进程重启，不是语义故障修复。重复页面故障须停用对应任务。
5. 手动接管在非战斗窗口设置PAUSE；确认supervisor_stopped与ALAS进程退出后点击。不能只杀子进程，否则守护会重启。
6. 接管完成保存图，回支持主页，显式resume并重开需要的进程。异地登录或用户暂停需用户明确恢复。
7. 报告器 `scripts/start.ps1 -Mode reporter` 独立运行：两小时槽位、PAUSE 即退出、失败不重发；收据见 `runtime/mail-receipts.jsonl`。
8. 观察器识别到登录/重新登录页会自动创建 PAUSE 并尽力发送邮件提醒（顶号闭环，需 vision_enabled）；恢复前须人工核验支持主页。

## 日常与委托

ALAS承担已支持任务，Daily/Hard/Exercise/Reward/Tactical/Dorm分别核验。任务结束日志不等于所有挑战已完成：可能锁定、跳过或失败，报告分别写实际情况。

已完成委托及时收取，保留奖励弹窗；页面无待收不重复领取。“作战委托占用”先点查看核验，00:00且完成计数达标可收取并离开；仍在运行就等待，不能只看占用文字永久延后。自动推荐失败保持关闭，主管按图派闲置船/免费低耗委托，不拆出击队、不接受高耗油委托。

建造、科研先核验当天任务与已有项目，完成后收取；不重复花资源满足已经完成的任务。科研队列可能多页弹窗，逐页保存，不能一次点击就宣称全部收完。

## 训练、心情与船坞

训练用已有两槽T1蓝色品质，技能类别红蓝黄均可；按真实结束时刻本地ALAS续训，不等两小时主管。蓝书不足/学生满级要核验，不扩槽不花钻。

心情以当前船员截图为准；记录最低值、时间和后宅成员。calculate/prevent_green_face；全队20/h仅作为保守计划参数，不能填成实际心情。后宅已有位置优先轮换低心情成员，用户自行更换后以新图更新，不恢复旧队伍。追加普通出击前再读图；资源不足休息是正常状态。

船坞满停止高频出击。只经核验使用白蓝材料强化金船，保护稀有金紫、布里和待练船；默认项目不自动清船坞。

## 普通主线补星

每章截图区分亮星和暗星，局部复核缺星。单关map_3_stars、StageIncrease=false、RunCount=1，再核验最终星数；防无限循环和越界。心情和OilLimit限制优先于补星。旧关卡列表不带到新账号/新日期。

## 大世界

先检查剧情进度、可进入区域、日常任务板和自动搜索按钮。旧实践有NY区域初始化/名字匹配卡住、日常任务板LOCKED、无自动搜索；这些都是观察，不足以确定某章剧情未完成。

未验收前OpsiDaily/OpsiExplore关闭。主管可按图完成可用剧情；仅已有AP/免费补给，不买AP油钻。区域进入耗AP不等于完成清图。只有确认支持页面、自动搜索、任务退出和奖励收据后才有限启用ALAS。异常重复停用任务并保存原图/短日志，防阻塞其他日常。

## PT与过期活动

每日与历史奖励单列。每次领取要前状态、奖励弹窗、后余额；观察claimable不代表到账。整图曾把500读成300、暗星读成亮星：使用局部放大/独立OCR并主管审核，不自动替换猜测数字。

活动入口、截止、商店库存价格每天复核。旧38000余额仅历史案例，不能作为现在可兑换。兑换计划与实际兑换分开；无入口就报告无法核验，不自动花货币。
