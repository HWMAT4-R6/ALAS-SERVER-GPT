# 迁移清单与验收范围

| 原实现 | 新项目处理 |
|---|---|
| run_alas_10h.py | 参数化路径；唯一锁、暂停、有限重启；只停止自己的子进程 |
| 固定日期monitor.py | 移除10月4日至5日窗口；通用观察器、connect、变化检测、离线不调用API |
| workers.py | 保留JSON、超时、重试与锁；模型/端点/价格可配置；移除历史每日PT仅200/500规则 |
| capture.py | 参数化serial，校验退出码与PNG |
| 旧configure/fix脚本 | 仅记入调试案例，不自动执行过期活动/串口/强化补丁 |
| 日常状态、PT、编队和心情 | 在服务器重新截图；不携带历史当前值 |
| Codex/Gmail | 需要服务器重新配置主管及授权；项目只产草稿 |

## 验收次序

1. 离线测试与语法检查通过；源码无密钥/账号/旧机器路径。
2. 服务器版本清单：OS/P620驱动/VT/雷电/游戏渠道/ALAS提交/Python/ADB。
3. 连接与1280×720截图有效；远程连接、断开和锁屏后分别测试。
4. 支持主页、唯一进程、PAUSE拒绝启动、暂停停止、显式恢复。
5. 两槽T1训练准时收取与续训，确认真实结束时刻。
6. 日常逐项验收，已完成委托与科研实际收据、油与心情有新图。
7. 大世界单独解锁与页面识别验收，通过前保持关闭。
8. 至少30张不同图覆盖各种页面和异常，统计字段准确率/拒绝率/接管；不是仅看JSON合法。
9. 一天试运行记录有效在线时长、真实完成率、资源变化与费用；数据缺失如实标记。

不保证旧账号已到的关卡在新账号可用，不保证当前活动和历史PT奖励一致。发布完成≠服务器部署成功≠完全无人值守。

## 不包含的自动化

安装模拟器/游戏、游戏登录、购买资源、具体游戏手动点击、自动稀有船处理、剧情解锁、邮件直接发送、Codex唤醒、自动更新ALAS源码。已有ALAS功能和主管接管完成这些流程中的授权部分，项目不伪装为已实现。
