# 调试与恢复：先证据，后修改

每个故障保存新截图、时间、最后50行日志、任务名、serial及版本；仅发送必要摘要给Assembler。不要把全量日志反复交给GPT，也不要让模型自动改源码。

| 现象 | 验证 | 处理与恢复条件 |
|---|---|---|
| ADB无设备 | 先connect，检查devices/get-state、实际端口、PNG头 | 不自行启动关闭的模拟器；本地退避；用户打开后重新截图 |
| 别处登录 | 新图确证登录提示 | PAUSE、停守护和ALAS，等待用户明确恢复，不抢手机登录 |
| 卡在页面识别 | 保存截图、UI日志、版本；区分截图失败与页面不支持 | 停失败任务，手动非战斗窗口回支持主页，有限重试，不改随机坐标 |
| 大世界ZONE INIT/Get zone name循环 | NY/港内/海域图分别检查；自动搜索、任务板、剧情进度分别核验 | 关闭Opsi；可按图继续剧情，解锁后单次验收；不能称清图成功 |
| 出击提示作战委托占用 | 查看委托剩余时长及完成计数 | 已完成实际验收后离开；未完成等待，勿重复派发 |
| 委托自动推荐失败 | 队伍/委托要求/闲置船 | 保持自动推荐关，手动免费低耗候选；不拆出击队 |
| 船坞满 | 当前船坞容量、白蓝材料、稀有锁定 | 主管核验清理；不随机退役、不沿用旧强化补丁 |
| 油不足或心情不足 | 当前油与实际最低心情 | 免费补给可核验领取；保留储备后休息；这不是故障 |
| 模型500读300、暗星读亮星 | 局部放大/独立OCR，和原图比 | 标记不确定并接管，不自动“修正”成期望值 |
| API401/403 | 脱敏HTTP状态、密钥是否配置、账户权限 | 不重试这类认证错误；用户本地修复凭据 |
| API429/5xx/超时 | usage开始/失败记录 | 最多两次指数退避；失败费用未知；不循环唤醒GPT |
| 守护已启动但ALAS未运行 | events、alas.log、实际子进程 | launcher PID不是成功；已有ALAS/PAUSE/离线会拒绝启动 |
| 锁文件还存在 | Windows文件锁是否仍占用、实际进程 | 锁文件存在本身不是锁占用，退出会释放；不靠删文件抢锁 |
| PAUSE后仍有进程 | 等待当前API超时、查process与supervisor_stopped | 守护每秒检测暂停，先结束自己的ALAS；观察器正在API请求时可能等30秒 |
| 远程断开黑屏 | 对比连接/断开/锁屏PNG、驱动与会话 | 不注销交互式会话；现场查渲染，不能通过改截图延时假装修复 |

## 源码补丁规则

历史串口异常曾与源码中的 `chr(8) + v` 路径有关，旧脚本直接字符串删除。此补丁依赖特定版本；新服务器先记录ALAS提交、serial repr与复现，优先官方修复。不能不检查版本就运行旧fix脚本。

历史 `configure_alas_run.py` 有OilLimit500、过期活动、StageIncrease和全船强化；迁移时废弃，不能把“部署脚本”当安全默认。

## 修复验收

确认单一根因、保存备份、只改相关项；先只读截图，再单次任务运行，保存前后证据。连续错误触发主管接管，不把无变化轮询写成进展。恢复必须到支持主页且无战斗，不是仅证明进程存在。
